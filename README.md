## [/advance](./advance/SKILL.md)

[/advance](./advance/SKILL.md) skill utilizes allows parallel work to be automatically progressed by an orchestrator agent. It relies on [gbiv](https://github.com/jmbeach/gbiv) for orchestration, [vat](https://github.com/jmbeach/vat) for task management, and [LID](https://github.com/jszmajda/lid) for spec-driven development. It lets the work flow through a state machine where it unblocks PR's to get them to a mergeable state.
